فایل‌های فونت یکان (مجاز و دارای لایسنس) را اینجا قرار دهید:

  Yekan-Regular.woff2   (وزن ۴۰۰)
  Yekan-Bold.woff2      (وزن ۷۰۰ — اختیاری)

پسوندهای .woff و .ttf هم پذیرفته می‌شوند. سپس اجرا کنید:  npm run brand
(به‌صورت خودکار قبل از dev و build هم اجرا می‌شود.)

اگر فقط یک فایل وجود داشته باشد برای هر دو وزن استفاده می‌شود.
تا زمانی که فایل یکان نباشد، فونت Vazirmatn (بسته‌شده محلی در Build) و سپس Tahoma
جایگزین است و برنامه ادعا نمی‌کند که یکان فعال است.
